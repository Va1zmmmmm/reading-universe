先追一个问题，
再带入自己的阅读。

页间把阅读材料整理成可以选择去路的线索。每处先讲清语境，再读材料；你决定接着追哪个问题，也可以回头、留笔记或停下来。

还没有准备材料？先试玩。

打开完整试玩项目 ↗，无需注册或 API key。它包含6份原创示例手记、独处／记忆／选择3条线索，共18处。可以查看完整材料、切换主题、写笔记和保存项目，下一次重新导入继续。

试玩文字由 AI 协助创作并逐处审阅，不是真实书摘或作者私人笔记。作者公开书目是另一份已公开的书单案例，只有元数据，不能代替完整问题探索。

用自己的内容，有两种起步方式。

  1. 没有导出文件：首页选择“粘贴文字开始”。填书名或笔记名字，选择真实的来源种类，粘贴文字；空行分隔成独立材料。你也可以从自己的读书摘记开始，不要求使用电子书平台。
  2. 已有资料：打开一个项目 JSON、资料 ZIP 或文件夹。书目用 books.json，其中每本有 bookId或id、title；可一同带入 highlights/{bookId}.json、notes/{bookId}.md、cards/{bookId}.md。微信读书资料需先导出，网站不会登录或自动抓取你的账号。下载书目格式示例；完整格式说明 ↗。

怎样长出自己的线索？

  1. 打开项目后先翻材料，再点“整理新线索”。起一个主题名，可写一句想追问的问题。
  2. 至少选择两段材料。可以改选材料中的连续片段，不能把改写的话当作引文。
  3. 展开“本次使用的 AI 服务”，填写服务商、实际可用的模型名和自己的 API key。DeepSeek 已做真实小样本验证；OpenAI 内容生成仍未验证。费用由所选服务商收取，网站不提供代付额度。
  4. 整理后先沿草稿读几步，检查引入、引文和衔接。确认合适再加入项目；不合适可返回重选。
网站检查结构和引文是否与输入材料一致，这不等于 AI 的理解一定正确。只有书目时能看图谱与星空，不能凭书名编造具体材料或探索段落。

怎样保存和分享？

“保存项目”下载完整私人 JSON，保留材料、线索、发现记录和个人笔记。刷新或离开前请保存；下次打开该文件继续。图谱与星空在另一个完整入口，打开同一项目即可使用，也能从图谱进入问题探索。

“分享精选”先选书目，再逐项选择主题、解读和引文，预览后下载可离线打开的网站包。你的个人笔记、完整原材料、未选内容和原探索记录不会自动公开；公开包内的内容任何收到它的人都可读取。

文件与 AI 的边界

原始文件在浏览器读取。开始 AI 整理时，所选书名、作者、问题和片段会经过网站的临时服务，发送给所选服务商。其余材料不发送。网站不保存 key，任务结束清理临时输入；服务商的数据规则取决于你自己的账户。

免注册，没有私人云端档案。浏览器关闭或页面刷新会失去未保存的内容；服务重启或任务超过15分钟也可能丢失未取回结果。

遇到错误：先保存项目，再到 GitHub Issues 反馈卡在哪一步。不要上传 API key、完整私人项目或未打码的截图。新域名若在代理网络下打不开，可切换到可正常访问的网络；临时试玩地址不作为长期入口。
