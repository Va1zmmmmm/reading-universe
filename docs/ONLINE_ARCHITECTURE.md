# 在线版架构与运行边界

浏览器读取原始文件 → 标准私人项目 → 本地双视图/人工修改。
需要 AI 时：浏览器提交选定片段 + 当前 key → 所属匿名会话的临时任务 → 服务商调用 → 校验结果 → 浏览器取回并删除任务。

## 数据与密钥

- 原始文件不上传。每本默认取前 12 段、每段最多 1500 字、每本总共最多 6000 字；界面注明截取策略与费用条件。
- 临时任务在进程内存，15 分钟过期清理；完成后清除输入和 key，浏览器取回结果后主动删除任务。错误仅返回固定说明，不返回提供方响应原文。
- key 不写磁盘、项目包、localStorage 或日志。用户取消时服务端移除任务与 key 字段；已开始的网络调用及其调用栈需等请求返回/超时才释放，不能撤销已发给服务商的调用。服务商留存遵循其自身政策。
- 进程重启会丢失任务；浏览器保留已完成项目部分，重新填 key 后可续跑。首版采用纯内存任务，尚未实现跨服务重启恢复排队任务，不声称具备持久任务表。
- 匿名会话 cookie 为 HttpOnly/SameSite=Strict；HTTPS 代理设置 X-Forwarded-Proto 后加 Secure。每个接口检查所属会话；任务 ID 不代替授权。
- 固定提供方端点，不接收用户填写任意 URL；服务商请求禁止跳转。每会话一个运行任务、每小时最多 300 个任务、全局最多 100 个保留任务、4 个工作线程。
- 生产环境必须配置 READING_ORIGINS；反向代理启用 TLS，并覆盖 Host/X-Forwarded-Proto。自带 key 的页面不得嵌第三方统计/广告脚本。

## 问题线索生成（2026-10-10，本机探索试版）

- `/api/session` 声明 books / links / exploration 阶段；探索请求使用同一 `/api/jobs`，不新增独立任务服务。正式 `web/core.mjs` 导出 explorationRequest / validateExploration，具体契约实现位于 web/exploration.mjs，服务端 exploration.py 再校验。
- exploration 只接显式勾选的真实片段：2–32段、最多8本书、单书12段、每段1500字、总共24000字；附书名/作者、材料类型和本次主题/问题。不同于上方旧书籍分析的默认截取策略，不提交已有主题、来路与探索笔记。
- 结果按白名单重建。所有引用逐字属于提交片段，节点可达、目标合法、引用不重复，至少2处与一个自然停留；3处及以上须有至少一处分支。每处语境、观察与每次转向的理由不得为空。书评/笔记/卡片不得冒充作者原话。
- 双端校验后仍先预览，用户确认才追加主题，保留既有笔记和路线；basis=ai-draft 标识延续到保存恢复。字段/引文校验不能代替人工判断讲述准确性。
- 沿用匿名所属、限额、重试和清理；结构失败不自动重跑，网络/指定HTTP错误最多2次。探索网络超时90秒，输出上限8192；截断和内容过滤拒绝导入。OpenAI 使用 max_completion_tokens 与 store:false，DeepSeek 使用 max_tokens；参数按官方接口文档核对，尚未真实提供方验证。
- `--explore-preview` 默认关闭，仅允许127.0.0.1/localhost绑定并检查请求Host，`/explore/` 只开放必要资产白名单；不开放私人目录遍历、缓存与文档。独立克隆发布仓不带作者私人预览材料。
- 该页面在开发工作库 design-preview/compose.html，探索包为 reading-atlas-workspace v1；尚未与正式私人包无损双向适配，也未接入公开导出。本机流程验证通过，不代表上线或真实内容验收。

## 2026-10-10 正式探索入口与完整项目往返

web/atlas/index.html 已成为同服务的独立入口，不依赖私人 design-preview 或 --explore-preview。默认空白，作者按钮只读现有公开案例；复制 web、server.py、exploration.py 到全新目录也可运行。UI模板同步工具 tools/sync_exploration.mjs 不复制作者原文或分支。

atlas-project.mjs 统一探索导入/来源/保存恢复，universe-fields.mjs 统一旧元数据允许字段；core.mjs 支持两个项目格式往返，保留已定义的关联、缓存、人工修订、设置、指标与材料稳定ID。原书目标签和显示标签分开，保存不误触发缓存分析。新书单若破坏探索引用则拒绝覆盖，当前项目保留。

同源窗口交接只在内存中传项目，校验origin、对应WindowProxy和会话随机值；不是上传或URL参数。探索“带回图谱”是显式动作，父页并发改变则拒绝覆盖，双方各自下载。正式探索下载同一私人包，后续重开恢复所有主题记录。

“分享精选”默认复用publicProject和原静态渲染。用户批准显式开放精选探索后，publicExploration/atlas-sharing.mjs 从完整私人项目回查原文与公开书目，按每主题开场、每节点解读及单独引文权限重建 reading-atlas-public v1。只保留选中且从开场可达的线索，去路同步裁剪、主题/节点重编号，不输出私人来路、笔记、完整材料和定位符。改变范围清除预览；资源异步读取期间改变选择阻止旧包下载。

public-atlas-contract.mjs 为独立公开白名单与结构校验；public-reader-runtime.js 渲染所选公开内容，经 tools/build_public_reader.mjs 打包为普通脚本，离线 file:// 无模块/后端依赖。public-data.js 仅含白名单公开数据，index.html 是探索，graph.html 复用图谱/星空；访客从开场开始，每节点只记录首次发现，主题各自保留进度，URL 不含私人文本/定位符，不持久保存访客状态。没有服务请求或公开素材远程依赖。上述早期“未接正式私人包/公开导出”描述由本节更新；真实模型与公网验收仍未完成。

## 项目保存、更新与公开

- 下载“私人项目”白名单字段，保留证据、分析、手改和缓存，忽略 key/会话字段。不能拿私人包当公开包。
- 默认新导入完全替换当前项目。只有用户勾选“当前项目的最新完整书单”时按 ID 保留人工修改；不在新书单中的书及关联被删除。已有人工主题卡可能继续提到删掉的书，需要本人修订；公开导出始终重建卡片。
- 缓存书籍分析按材料、词表与模型哈希；关系包括“核对后没有关系”的结果也缓存。人工移除配对留删除标记，防止重跑复活。
- 分享默认只导出书名/作者/主题与选中的关联结构；时长与笔记数可选。原文、日期、评分、自由文字和私人理由均不进入首版公开包。公开卡片重新由允许书目生成。
- 公开包为可离线打开的静态 ZIP；探索页可按主题/节点显式公开解读与引文，图谱页仍是保守书目导出，图片分享为聚合主题海报。尚无云端一键分享链接、日期开放或阅读时间演变功能。

## 格式与渲染

web/core.mjs 为唯一标准化、图谱/宇宙构建及导出核心；web/app.mjs 为操作入口；web/viewer.html 与 universe.js 复用原渲染器。
作者案例在 web/examples/author-public.json，只能显式加载。仓库 data/ 是历史公开样例和迁移输入，在线用户不读取它作为工作空间。

ZIP 在浏览器解压：限 20 MB 压缩、40 MB 解压、4000 文件，单文件 4 MB；只接受 JSON/Markdown，拒绝危险路径、符号链接、加密、嵌套压缩和高压缩比。服务端再次校验收到的分析结构和大小，但不接收 ZIP 原包。
外来文本不执行脚本；图谱 tooltip、标题、书籍描述和 Markdown 都先转义。仅同源 iframe 消费父页面的项目对象，公开包读取自己的数据文件。
