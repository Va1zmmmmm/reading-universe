# v0.2.0-beta.2 · 页间公开测试版

在 v0.2.0-beta.1 的完整在线工具基础上，本版集中修复公开分享安全、异步导出时序和阅读工具的三项问题。

## 本次修复

- **公开分享书名碰撞**：所选书标题与未公开书目（含排除书目）标题冲突时，整次阻止预览/导出并提示“书名冲突”，不再静默剔除所选书；错误和公开产物不泄露隐藏书名、私人笔记或完整材料。
- **公开分享异步失效**：选择变化、后续操作或冲突失败后，旧预览/下载任务即使完成，也不会下载旧 ZIP、替换预览或覆盖当前提示；成功公开对象不再有孤儿 analysis，关联只指向最终公开书目。
- **生成并发锁**：连续点击“生成主题与关联”只允许一轮进入；失败、取消或成功后均释放状态。
- **历史引用与 AI 勾选**：`included=false` 只表示“不发送给 AI”；已保存探索引文仍可保存、重开，AI 请求闸保持关闭。
- **空书目/全彗星宇宙**：空项目显示空状态不抛错；全部为彗星的小书目可获得初始可见视野，正常书目构图与彗星判定不变。

## 本次附件
