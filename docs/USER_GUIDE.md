# 使用阅读宇宙

## 第一次来

打开 <https://atlas.va1z.xyz/atlas/index.html> 使用完整工具。选择“先试玩一条线索”，可直接体验3条主题、18处探索，无需注册或 API key。试玩是 AI 协助创作并逐处审阅的原创虚构手记，不是真实书摘或作者私人笔记；可写笔记、保存与分享，功能与自己的项目相同。

没有导出文件，也可以选“粘贴文字开始”：填书名或笔记名字，选择真实来源种类，空行分段。带入后按材料浏览，至少两段可整理问题线索。支持从纸书笔记开始；微信读书文件需自行导出，网站不会登录或自动抓取账号。已有未保存的项目会先提示保存，不会静默覆盖。

完整入门说明：<https://atlas.va1z.xyz/guide.html>。试玩无需模型；用自己的内容生成草稿需自带 key，费用由服务商收取。DeepSeek 已做真实小样本调用；OpenAI 真实内容生成未验证。

## 沿问题探索

首页选择“从问题开始”，也可在已有图谱中点“从问题探索”带入当前项目。打开自己的书目、划线、书评、笔记或读书卡；作者按钮仅展示公开案例，与自己的项目分开。

点击“整理新线索”，给线索起名，可写一句想追的问题；勾选几段真实材料，填本次模型和自己的key。先沿草稿读几步，检查引入、语境与衔接，认可后加入项目；原主题和笔记保留。只有书单时先翻书目，不会编造原文探索。

保存完整私人项目后，下次重新打开可以继续。两种旧项目格式都能读取，已定义的原关联、修订、设置与阅读指标也会保留。探索页“带回图谱”可把成果送回；图谱页期间发生修改时会阻止覆盖，可分别保存。手机的书目、分享与返回操作在“更多”里。

“分享精选”先选择书目；不启用探索时，仍只导出图谱。勾选“让访客沿精选线索探索”，展开主题：选择主题，确认以上开场与停留说明，保留想分享的节点，逐处确认解读与去路说明，再分别选择是否公开引文。引文默认不开。开场必须保留，所选分支必须从开场走得到；如果解读提到隐藏的书，要纳入书目范围或先修订文字。

点击“看看公开版”，沿访客路线读几步，再下载公开网站包。改变选择会清除旧预览；下载准备期间改变范围会取消旧下载。公开探索包解压后打开 index.html 即可游玩，graph.html 是书目图谱，graph.html?universe 是星空，不需要登录或模型服务。访客从开场开始，不继承你的来路、收藏或个人笔记；不自动保存访客记录。公开包的所有内容都能被读取，应按内容本身选择公开范围。

只公开确认的解读和引文，不附完整原材料、来源编号、私人笔记、日期和评分。未公开引文会明确标出，书评与笔记也会按真实来源种类显示。AI 草稿来源标识保留；结构和引用检查不代替自己审阅讲述质量。

## 创建自己的版图

1. 打开网站，选择“创建我的版图”。书目需有 books 数组，每本含 bookId 或 id，以及 title。author、readingTime（秒）、notes（数量）可选。首页可下载示例。
2. 可选：一同选择 highlights/{bookId}.json、notes/{bookId}.md、cards/{bookId}.md、cards/links/*.md、theme_tags.json、themes/*.md、links.json。支持选择文件夹或把以上 JSON/Markdown 打成普通 ZIP。
3. 所有文件在浏览器读取，原始文件不上传；仅书目也能看图谱与星空。作者案例必须单独选择，不会混入你的书架。
4. 要生成主题与具体关联，填写自己的 DeepSeek 或 OpenAI API key 和模型名。主题词表可留空，同义词可按“别名=标准名”填写。模型必须由你的服务商账户实际支持。
5. 展开“查看材料与修订内容”可取消某段材料的 AI 分析勾选。每本发送勾选片段中的前 12 段、每段前 1500 字、每本总共最多 6000 字。开始前确认 AI 使用说明；片段会临时经过网站后端并发送给服务商。
6. 分析按每批 8 本运行。已完成结果保留，可取消或再次填写 key 续跑。每轮最多核对 40 对候选书间关联；没有证据可以不连线。
7. 图谱中看主题和关联，宇宙中看书架结构。可以修订书籍主题、主题卡、添加本人确认的关联，也可以移除自动关联。

## 保存与更新

“保存我的项目”下载私人 JSON 包：含原材料、分析结果、人工修改、词表与缓存，不含 key。刷新、关闭页面或切换项目之前请先保存。下次选择该包即可恢复。

默认每次导入都是全新独立项目。若这是同一项目的最新完整书单，先勾选相应选项再导入：相同 ID 保留人工修改，不在新书单中的书删除。书名和版本变化需要保持/修正 ID；相同书名不代表相同版本。

服务端任务为临时内存状态。进程重启或任务过期时，尚未取回的结果可能丢失，需重填 key；下载项目包才是长期保存方式。

## 公开分享

选择“导出公开版”后勾选书目，可选择是否公开阅读时长、笔记数与在库书之间的关联结构。先预览，再下载静态网站 ZIP 或主题海报图片。

首版公开包不含划线原文、日期、评分、自由文字、私人关联理由，也不导出未单独选择的库外书/概念标签。专题卡由公开书目重建。允许的主题标签本身也会透露兴趣，分享前请看预览并修订不想公开的标签。

解压后打开 index.html 是图谱，index.html?universe 是星空；可将解压文件部署到静态托管。没有注册、云端私人档案或一键分享链接。

## 数据与效果

仅书名分析属于推断；有划线、笔记时可解释具体依据；导入旧卡与关联会标为已有整理，不声称已重新回查原书。AI 结果需要本人审阅，不保证每本都找到有效关联，也不从书单编造人生变化。

首版支持最多 1500 本书；文件总量限 20 MB，ZIP 解压后限 40 MB/4000 文件。压缩包不能含图片、可执行文件、加密条目或嵌套 ZIP。无效材料会给出提示，原文件不改写。
